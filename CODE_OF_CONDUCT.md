# Code of conduct

## The short version

Be decent. Technical criticism is welcome and expected — this project's own
documentation criticises its author's earlier decisions at length. Personal
attacks, harassment, and dismissal of people rather than arguments are not.

## Scope

Issues, pull requests, commit messages, and any other space where you are
representing this project.

## Not acceptable

- Harassment, insults, or discriminatory language about anyone's identity.
- Sexual attention or advances.
- Publishing someone's private information without permission.
- Sustained disruption: reopening settled decisions without new evidence,
  derailing threads, or arguing in bad faith.
- Dismissing a report of a problem because you cannot reproduce it. This project
  has shipped several defects that only appear on another platform or another
  font set; "works for me" is not an answer.

## Enforcement

The maintainer may edit or delete comments, close issues and pull requests, and
block accounts. There is one maintainer, so there is no committee and no appeals
process; that is a limitation of a small project rather than a design goal.

Report a problem through the repository's issue tracker, or privately through the
contact route in [SECURITY.md](SECURITY.md) if the report itself is sensitive.

## Attribution

This is a short project-specific statement rather than an adopted code of conduct.
The [Contributor Covenant](https://www.contributor-covenant.org/) is the usual
choice for projects that want a fuller one; adopt it if this project grows past a
single maintainer.
